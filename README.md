Entry for the make.fun micro competition [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

The brief asks for exactly one word: the word grandma would text about AI.
This entry writes a single word to `/output/entry.txt`:

**Sweetiebot**

Why it fits: grandma greets every new thing with an endearment, so she
affectionately names the AI "Sweetiebot" — warm, a little baffled, funny in
one word, and unmistakably tied to a robot/AI rather than any other subject.

## Run

```sh
python3 main.py
```

It writes `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Standard library only — no third-party dependencies.
